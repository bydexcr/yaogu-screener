# 大A小散 · 妖股低吸雷达 + 个股综合分析

本地运行的 A 股看板：同花顺 REST 直连、**零第三方依赖**，一个 Web 层同时服务电脑浏览器和安卓 App 的 WebView。

三个页面：

| 页面 | 内容 |
|---|---|
| **个股分析** `/` | 市场全景（涨跌分布 / 热门板块 / 涨停·跌停·炸板池 / 连板梯队 / 热股榜·龙虎榜·成交额榜）+ 搜股后的 16 章深度分析 |
| **自选股** `/watchlist` | 自选列表：实时行情 + T-1 涨幅 + **今日是否在雷达池（候选/命中/深水/承接/走弱）** + 备注；拖拽排序、批量粘贴导入、CSV 导出。电脑端为主库，手机端配置电脑地址后自动同步 |
| **妖股雷达** `/radar` | T-1 强势（>8%、主板、成交额≥10亿）、T 日低开 -10%~-3% 的低吸信号：候选池、低开命中时间线、深水副栏、承接/走弱动态、情绪与板块资金矩阵 |
| **复盘** `/review` | 当日盘面复盘：一句话总收口 / 盘型环境 / 资金流证据 / 主线轮动 / 高度单元 / 四分层 / 次日观察与证伪 / 股票池更新 / 风险边界 |

## 一、这个仓库里有什么

| 路径 | 作用 |
|---|---|
| `web/` | **Web 层（唯一源）**：三个页面 + 零依赖 HTTP 服务 + 数据层 + 分析/复盘引擎 |
| `mobile/` | 手机端主循环（REST 直连，不依赖 DuckDB）+ 系统通知 |
| `strategy.py` | 低吸策略纯函数（C1~C5 条件、日内承接/走弱判定、候选评分） |
| `android/` | 安卓壳：Chaquopy + WebView + 前台服务 + 设置页 |
| `scripts/check_sync.py` | 校验 `web/` ↔ `android/.../web/` ↔ `mobile/` ↔ `strategy.py` 一致 |
| `.github/workflows/` | `build-apk.yml` 云构建 APK；`check.yml` 语法 / 生成物一致 / 副本一致 |
| `docs/PC_ENGINE.md` | PC 引擎说明（**历史参考**，其文件不在本仓库） |

## 二、不在本仓库的内容（重要）

本仓库是**「App + Web 层 + 策略函数」的子集**，不含 PC 端引擎：

| 不在本仓库 | 说明 |
|---|---|
| `screener.py` / `config.json` / `start_screener.ps1` … | PC 常驻看板程序与其配置 |
| `datasource/`、`notifier.py`、`data/market.duckdb` | 本地全市场 DuckDB 数据源、推送、行情库 |
| `sector_flow.py` | 板块资金矩阵（量价 + 龙虎榜 + 涨停结构三证据交叉） |
| `backtest.py` / `grid_search.py` | 离线回测、参数网格寻优 |

这些在 PC 项目目录里；**在本仓库按 README 找它们是找不到的**（旧版 README 曾混在一起描述，已拆分）。
如果你只想要"能看盘 + 能分析个股 + 能复盘"，本仓库就够了；
如果你要"全市场 DuckDB + 板块资金矩阵 + 回测 + 寻优"，去 PC 项目，并把 `web/` 同步过去（见 [CONTRIBUTING.md](CONTRIBUTING.md)）。

## 三、快速开始

### A. 装到手机（推荐，无需本地环境）

1. 仓库 → **Actions → build-apk → Run workflow**（约 2~10 分钟）
2. 下载产物 `daxiaosan-v<版本>-apks`，装 `release/*.apk`（允许"未知来源"）
3. 首次打开填同花顺 **API Key**，点「保存并启动」

版本号与签名的细节（怎么做到"覆盖安装不用卸载"）见 [README_APP.md](README_APP.md)。

### B. 在电脑上看页面

```powershell
python web/dev_server.py      # http://127.0.0.1:8399
```

这是**联调模式**：个股分析与复盘可以用真实数据看，妖股雷达页只有骨架（没有候选池引擎）。
要看完整功能请装 App，或使用 PC 项目的引擎（不在本仓库）。

## 四、数据与口径（摘要）

- 数据源：同花顺 REST（`https://fuyao.aicubes.cn`，请求头 `X-api-key`）。
- **同花顺 REST 没有官方「主力资金 / 大单资金」指标**：复盘页的「资金流证据」用**龙虎榜净额**，页面上已标注口径。
- 龙虎榜每日只覆盖数十只上榜股，不代表全市场资金；概念聚合时同一只票会计入其所有概念，金额不可加总。

完整口径、接口清单、版式与主题说明见 [README_WEB.md](README_WEB.md)。
